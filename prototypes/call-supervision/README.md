# call-supervision

通话录音实时沟通步骤督导（V1）。

## 要验证什么

- 员工在通话中能否一眼看出：哪些步骤已完成、哪些待完成、当前该做什么
- 提醒是否出现在合适的时机，且不打扰正常沟通
- 管理员能否配规则、看记录、定位到原始证据

## 页面

| 页面 | 说明 |
|---|---|
| 实时督导 | 员工端通话工作台面板：规则名、通话状态、步骤清单、提醒区 |
| 督导规则 | 规则列表 + 新建/编辑：基础信息、适用范围、步骤配置 |
| 督导记录 | 记录列表 + 详情：步骤执行情况、提醒记录、识别证据 |

## V1 边界

- 仅电话通话
- 只判断步骤是否完成，不评价沟通质量，不提供话术建议
- 不做敏感词实时提醒、知识检索、风险识别、沟通质量评分
- 员工不能手动修改步骤状态

## 步骤类型

- 行为执行型：员工主动执行了沟通行为
- 信息确认型：通话中获取到明确有效的信息
- 业务告知型：员工向客户传达了指定业务内容
